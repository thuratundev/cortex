## Create Bulk Feed

curl --request POST \
  --url http://192.168.48.36/feedbulk

## Create Query

curl --request POST \
  --url http://192.168.48.36/query \
  --header 'content-type: application/json' \
  --data '{
  "query": "အရောင်းစာရင်းကို ဘယ်လို သိနိင်မလဲ"
}'
